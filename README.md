## Исходный проект

В проекте уже реализованы:

- интерфейс `BaseAnalogClock`;
- класс `AnalogClock`, хранящий время как положение стрелок и признак `AM/PM`;
- интерфейс `BaseDigitalClock`, с которым должен работать клиентский код;
- `ClockFormatter` для форматирования времени;
- `ClockHistory` для хранения истории установленных значений;
- пример клиентского компонента `DigitalClockDisplay`.

## Важное требование

Adapter и Facade решают разные задачи.

- **Adapter** преобразует один интерфейс в другой.
- **Facade** предоставляет более простой интерфейс к подсистеме.

Не следует объединять их в один класс только потому, что оба используются в одной лабораторной работе.

## Описание решения

### Adapter

Клиентский код работает с интерфейсом `BaseDigitalClock`, то есть ему нужно время в виде datetime. А готовый класс `AnalogClock` хранит время как углы стрелок и признак AM/PM. Менять `AnalogClock` нельзя, поэтому я был реализован адаптер `AnalogToDigitalAdapter`.

Адаптер реализует `BaseDigitalClock`, а внутри хранит объект `AnalogClock`, который получает в конструкторе.

При установке времени `datetime` переводится в углы:

- часовая стрелка: `(hour % 12) * 30 + minute * 0.5`;
- минутная: `minute * 6`;
- секундная: `second * 6`;
- если час меньше 12 — AM, иначе PM.

При чтении всё наоборот: из углов получаются часы, минуты и секунды, а для PM к часам прибавляется 12. Полночь (00:00) — это 0° и AM, полдень (12:00) — 0° и PM.

### Facade

`ClockFacade`  это одна точка входа для работы с часами. Он сам создаёт `AnalogClock` с адаптером, `ClockFormatter` и `ClockHistory`, а клиенту оставляет четыре метода:

- `set_current_datetime(date)` — установить время (заодно оно записывается в историю);
- `get_current_datetime()` — получить текущее время;
- `get_formatted(fmt)` — получить время строкой, по умолчанию `ДД.ММ.ГГГГ чч:мм:сс`;
- `get_history()` — получить все установленные значения.

Своей логики у фасада нет, он только вызывает нужные компоненты. `app.py` теперь работает только через фасад.

### Чем они отличаются

Adapter подгоняет один интерфейс под другой: аналоговые часы → цифровой интерфейс. Facade упрощает работу сразу с несколькими компонентами. Поэтому это два отдельных класса, просто фасад использует адаптер внутри.
Тесты лежат в `tests/test_adapter.py` (преобразования, полночь, полдень, AM/PM) и `tests/test_facade.py` (фасад и история). Структурная диаграмма в `docs/`.
